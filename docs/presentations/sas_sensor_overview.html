The need

SAS algorithms need raw data with known truth.

Micronavigation, motion compensation, and image formation can only be tested well against echoes whose geometry is known exactly.

Coherent, multi-element

Complex baseband echo on every receiver element. Phase is preserved across hundreds of pings, which SAS focusing depends on.

Exact ground truth

True array pose and velocity at transmit time in every message. Downstream decides how much navigation error to add.

Repeatable scenes

Same world, seed, and parameters give bit-identical output. Regressions in processing code become visible.

Key decision · ADR-0001

Build the sensor. Nothing else.

The sensor behaves like hardware. One frozen message is the only coupling to the processing package.

How it works · one ping

Render the scene.
Synthesise the echo.

Every sensor update at the PRF produces exactly one ping under lockstep simulation.

  • 1
    Ray-cast the scene
    GPU (or CPU) ray image gives range and per-surface laser_retro strength.
  • 2
    Build world-fixed scatterers
    Surface quads, shadow rejection, voxels with hash-derived jitter and speckle.
  • 3
    Propagate to each element
    Two-way spreading, Thorp absorption, Lambert, beam patterns, receiver motion during flight.
  • 4
    Publish raw echo
    FFT convolution with the chirp, additive noise, SasPing with ground truth.

Why it focuses · ADR-0004

Same scatterer, every ping.

Ray hits move with the vehicle. SAS needs scatterers fixed to the world, with the same complex reflectivity each time they are seen.

01

Quantise to world voxels

Reconstructed surface is snapped to cell_size voxels (default 4 cm) keyed by integer world index.

02

Hash, don't draw

Jitter and speckle come from SplitMix64(CellKey ^ seed). No stateful RNG, so revisits are identical.

03

Deterministic noise

Receiver noise seeded per (seed, ping, element). Output does not depend on thread count or order.

Plan 008 · tests/validation

Prove the physics of the echo.

Seven checks on recorded bags. Image quality is tested downstream, not here.

V1 · Delay

Matched-filter peak at 2R/c ± 1 sample on every element.

V2 · Spreading + absorption

Amplitude follows 1/R² · Thorp within 1 dB at ≥ 3 ranges.

V3 · Beam pattern

Amplitude vs angle matches btx·brx within 1 dB to first null.

V4 · Coherence

Point-target phase follows e−j2πfcτ(t) predicted from pose.

V5 · Moving receiver

Per-element delay shift matches the model within 0.1 sample.

V6 · Determinism · V7 · Noise

Two runs bit-identical; empty-world std ≈ noise_std.
